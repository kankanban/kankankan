⚠️ Importante sobre notificações
  • Os alertas funcionam enquanto esta página estiver aberta (pode estar em outra aba ou minimizada). Eles aparecem no sino 🔔, como aviso na tela, com som e — se você autorizar e o navegador permitir — como notificação do sistema.
  • Com o navegador fechado, nenhum aviso é enviado. Para isso seria preciso: hospedar o sistema em um endereço https, instalá-lo como aplicativo (PWA com service worker) e ter um servidor de notificações push (ex.: Firebase Cloud Messaging ou Web Push) que dispare os avisos no horário certo.
  • No Chrome do Android, abrindo o arquivo HTML direto do celular, o navegador normalmente não permite notificações do sistema. Nesse caso os avisos continuam funcionando dentro do sistema (sino, aviso na tela e som).
  • Este sistema não simula notificações que não funcionam: se o navegador bloquear, você verá isso indicado acima.
